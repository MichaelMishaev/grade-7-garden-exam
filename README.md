# מבחן הבנת הנקרא לכיתה ז׳

אתר סטטי מותאם לטלפון הכולל טקסט קריאה, 20 שאלות ומסך בדיקה לפני שליחה.

התשובות נשלחות באמצעות [FormSubmit](https://formsubmit.co/) לכתובת הדוא״ל שהוגדרה בטופס. יש לאשר פעם אחת את הודעת ההפעלה ש־FormSubmit שולח לכתובת זו לאחר הגשת ניסיון ראשונה. עד האישור, השירות שומר הגשות ומעביר אותן לאחר הפעלת הטופס.

הטיוטה נשמרת ב־sessionStorage של הדפדפן בזמן העבודה ונמחקת בדף הסיום.
