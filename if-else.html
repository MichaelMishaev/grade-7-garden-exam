איך זה עובד?

אם התנאי מתקיים, מבצעים if. אחרת, מבצעים else. רק ענף אחד מתבצע.

נסו 60: >= כולל שוויון, ואילו > לא.

כל שלב נמשך 3 שניות. אפשר לעצור או להתקדם בעזרת ״השלב הבא״.

How does it work?

True → run if. False → run else. Only one branch runs.

Try 60. >= includes equal; > does not.

Each step lasts 3 seconds. Pause or step whenever you like.

Now you write the code.

Here you type real Python, like a real programmer. The computer reads your lines and answers.

  1. 1Read the mission in the green card.
  2. 2Change the code in the dark window. Tap a line to edit it.
  3. 3Press ▶ Run. The computer’s answer appears in the bottom window.
What are these two dark windows?

The top one is your code: the instructions you give the computer, one line at a time. The bottom one is the computer’s answer: when you press Run, it reads your code from top to bottom and prints there. Red text means it did not understand one line, and it tells you which line.
