# Maze screenshots

The game uses original 3D geometry; it does not require generated bitmap assets. Actual local browser screenshots are produced by `games/maze/tests/browser.mjs` under the uncommitted `output/maze/` evidence folder.

Views: mobile introduction, exploration, question, capture, guided recovery, map and completion; 320px exploration and desktop exploration/completion. Renderer-only evidence also lives under `output/maze-render-*.png`.

These are local prototype screenshots, not production evidence. See the [feature record](../small-maze.md) for verification results and limitations.
